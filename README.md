# Placement Management Portal

## 📌 Project Description

This project is a web-based application built with Python, Flask, SQLite, HTML, and CSS. It provides an automated campus placement management system with features such as student registration, company management, eligibility verification, and placement tracking.
---

## 🚀 Features

- Admin Login
- Dashboard
- Student Registration
- View, Edit & Delete Students
- Search Students
- Company Management
- Eligibility Verification
- Placement Tracking
- Placement Report
---

## 🛠 Technologies

- Python
- Flask
- SQLite
- HTML
- CSS

## ▶️ How To Run

1. Install Flask

```bash
pip install flask
```

2. Setup Database

```bash
python database.py
```

3. Run The Application

```bash
python app.py
```

4. Open Your Browser and Go To
```

http://127.0.0.1:5000
```
